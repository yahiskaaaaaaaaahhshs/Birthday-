# Only for Pratiti 🎀

All website files are at the repository root. There is **no `public/` folder**.

## Files
- `index.html` — the complete website (HTML, CSS and JavaScript in one file)
- `server.js` — Node/Express server and server-side passcode checks
- `package.json` — dependencies and start command
- `render.yaml` — Render deployment configuration

## Deploy on Render
1. Upload these files directly into the root of your GitHub repository.
2. In Render, create a **New Web Service** and connect that repository.
3. Build command: `npm install`
4. Start command: `npm start`
5. Set environment variables in Render:
   - `ENTRY_KEY` = `rajeevbkl`
   - `SECRET_KEY` = `rajeevbkl` (can be changed)
   - `SESSION_SECRET` = a long random private value
   - `NODE_ENV` = `production`

The `render.yaml` asks Render to prompt for the two passcodes and generates a session secret.

## Local testing
Install Node.js, then run `npm install` and `npm start`. Open `http://localhost:3000`.
